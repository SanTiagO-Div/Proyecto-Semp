Semp 
Proyecto universitario en donde se aplican conocimientos en creación web completa (CRUD). Busca resolver el problema de agendación de citas para una clínica odontológica entre más problemas que frecuentaba.

🛠️Tecnologías aplicadas: 
-Lenguaje principal: PHP
-Frontend: HTMLS, CSS, JavaScrip 
-Base de datos: MySQL
-Arquitectura: MVC (Modelo-Vista-Controlador)

📂 Estructura del Proyecto
app : Lógica principal y módulos de la aplicación
config : Archivos de configuración (conexión a BD, variables de entorno)
controllers : Controladores para la gestión de peticiones
models : Modelos de datos y consultas a la base de datos
index.css : Estilos globales
Index.html : Estructura visual de la vista principal
ndex.js : Interactividad y scripts del frontend
index.php : Punto de entrada principal de la aplicación

BASE DE DATOS
El proyecto utiliza una base de datos relacional para gestionar la información.
1. Conexión: La configuración de acceso a la base de datos se encuentra en la carpeta config/ (ajusta allí el host, usuario, contraseña y nombre de la BD).
2. Consultas y Operaciones (CRUD): Las operaciones con la base de datos se gestionan a través de los archivos de la carpeta models/.

Para la correcta ejecucion del pryecto es necesario la instalacion de un servidor local como XAMPP, WAMP o Laragon y un entorno PHP como MYSQL
